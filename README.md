# Quant Research Dashboard

A full-stack quantitative finance dashboard built using React, FastAPI, PostgreSQL, and Tailwind CSS.

## Features

- Portfolio tracking
- Stock analytics dashboard
- Technical indicators
- Strategy visualization
- Interactive charts
- Responsive fintech-style UI

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- JavaScript

### Backend
- FastAPI
- Python

### Database
- PostgreSQL
